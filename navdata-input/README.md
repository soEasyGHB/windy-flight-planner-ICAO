# Исходные данные AIRAC (не входят в ZIP проекта)

Для ручного запуска `build-navdata` через GitHub web UI загрузите в эту папку три файла X-Plane одного цикла:

- `earth_fix.dat`
- `earth_nav.dat`
- `earth_awy.dat`

Альтернативный вариант: в GitHub Actions → `sync-gdrive-navdata` (публичная Google Drive-папка с ОДНИМ ZIP, содержащим три файла).

Workflow генерирует `public/navdata/points.csv`, `airways.csv`, `manifest.json` и отправляет их в ветку `main`. Прямая загрузка исходных X-Plane файлов с iPad в плагин не нужна.

**Лицензия:** перед публикацией убедитесь, что права на входные файлы разрешают их обработку и публичное распространение. Коммерческие Navigraph/Jeppesen данные не следует публиковать без соответствующего разрешения. Навигационная база используется только для визуализации, не для навигации в реальном полёте.
