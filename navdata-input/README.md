# Исходные файлы AIRAC (не входят в ZIP)

Разместите **в папке `navdata-input/` репозитория** ровно три файла одного AIRAC:

- `earth_fix.dat`
- `earth_nav.dat`
- `earth_awy.dat`

Подготовьте три файла совместимого формата из одного AIRAC.

После GitHub commit workflow `build-navdata` конвертирует их в `public/navdata/points.csv`, `airways.csv`, `manifest.json`. Затем нажмите «Проверить базу данных» в настройках Windy-плагина. Альтернативно фоновый `sync-gdrive-navdata` получает архив `navdata.zip` из Google Drive папки `Windy-NAVDATA` при настроенной переменной источника. В интерфейсе плагина кнопка запуска этого процесса отсутствует.

**Права:** никогда не публикуйте навигационные данные, если условия лицензии не разрешают публичное распространение. Это не сертифицированный источник IFR-навигации.
