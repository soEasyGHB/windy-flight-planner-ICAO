# Проверка полного релиза v0.8.6

## Изменения

Исходный полный проект: v0.8.5. В версии v0.8.6 дополнен парсер `parseNamedFixRoute`, который пропускает коды ATS по схеме и не разворачивает их геометрию для главной карты и GPX. Обычный `parseRoute` оставлен для совместимости тестов и навигационной базы.

Добавлены сохранение пользовательского маршрута и ETD UTC в браузерном `localStorage`, стартовые «Грозы», расчёт FL360/TAS450, тёмно-серые блоки, компактные поля даты/времени. Поведение экспорта именованных GPX-фиксов сохранено.

## Локальные проверки

- `npm run check:tree` — список файлов и согласованная версия.
- `npm run check:imports` — локальные импорты.
- `npm run check:exports` — именованные экспорты.
- `npm run typecheck:core` — строгая проверка TypeScript для основных модулей.
- `npm test` — тесты маршрутов, Y12, импорта навбазы, GPX, ETA и интерфейса, а также Python-конвертера.
- После создания ZIP: независимая распаковка в пустую директорию и повторная проверка.

## Ограничения

`npm run build` / `npm run verify:release` требуют Rollup и Windy SDK. Если они не доступны локально, окончательное подтверждение сборки выполняется в Codespaces/GitHub Actions. Работу UI в мобильном Safari и фактическую доступность погодных слоёв Windy необходимо проверить на устройстве.

Навигационные CSV пользователя не включены и не подменяются. Визуализация по прямым между точками **не является воспроизведением ATS-маршрута**, а ETA без реальной геометрии и ветра условны.
