# Windy Flight Route Analyzer — 2.0.1

Упрощённый плагин Windy для визуализации маршрутов OFP/ICAO, экспорта GPX и открытия штатного IFR Route Planner с выбранным временем по сформированной ссылке.

## Интерфейс версии 2.0.1

- **Маршрут из OFP:** текстовое поле на восемь строк, «Построить маршрут» и «Очистить».
- **Планировщик полёта:** компактные, центрированные по вертикали дата/время UTC, кнопки «Скачать GPX» и «Сформировать план». После формирования появляется «Открыть планировщик».
- **Настройки → Ошибки и предупреждения:** диагностика маршрутов и GPX.
- **Настройки → Навигационные базы данных:** описание файлов AIRAC и папок, одна кнопка «Проверить базу данных».

### Передача маршрута в Windy

Формируется тот же URL `https://www.windy.com/route-planner/ifr/<lat,lon;...>?YYYY-MM-DD-HH`, который использовался в версии 1.2.3. Ветвь `/ifr/` уже выбирает IFR. Поскольку документированного параметра автоматического включения **Airspeed** не обнаружено, эта настройка не передаётся: при необходимости включайте её в Windy вручную.

URL округляет ETD до ближайшего *полного часа* (например, 05:31 → 06:00); при этом официально в публичных URL описаны трёхчасовые прогнозные слоты — поддержка произвольных часов зависит от Windy. В GPX исходное время UTC сохраняется с минутами.

## Обновление AIRAC

1. Откройте папку Google Drive [Windy-NAVDATA](https://drive.google.com/drive/folders/14eS_Ir19Uv7FPc2cVZWBR6_yKBvGTu5C).
2. В находящемся там архиве `navdata.zip` обновите три файла **одного цикла AIRAC**: `earth_fix.dat`, `earth_nav.dat`, `earth_awy.dat`.
3. Загрузите обновлённый `navdata.zip` вместо старого. После синхронизации откройте в плагине «Навигационные базы данных» → «Проверить базу данных».

Синхронизация работает по расписанию при наличии соответствующей настройки. Плагин не загружает исходные файлы непосредственно с устройства. Данные должны распространяться с разрешения правообладателя.

## Установка и ограничения

См. [INSTALL-v2.0.1.md](INSTALL-v2.0.1.md) и [AUDIT-v2.0.1.md](AUDIT-v2.0.1.md).

Плагин используется только для справочной визуализации, не для эксплуатационной IFR-навигации. Тропопауза, таблицы метеопрофиля, HTML/PDF-экспорт и погодные API не входят в проект.
