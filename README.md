# Windy Flight Route Analyzer — версия 1.0

Минималистичный плагин для визуализации маршрута OFP/ICAO на карте Windy и выгрузки маршрута в GPX. Версия `1.0.0` используется в `package.json` и конфигурации плагина.

## Главная страница

- **Ввод маршрута:** поле для маршрута и кнопки «Построить маршрут» / «Очистить». Подтверждённые FIX отображаются с подписями на карте.
- **Планировщик полёта:** по центру друг под другом дата вылета UTC и время вылета UTC; две кнопки «Скачать GPX» и «Открыть штатный планировщик Windy». Открытие штатного планировщика не передаёт маршрут или другие параметры.
- **Ошибки и предупреждения:** уведомление о готовности GPX, включая «Частичный GPX готов…», показывается **только внутри** раскрываемого раздела «Настройки → Ошибки и предупреждения» (при включённой детализации), а не под кнопками экспорта.
- **Навигационные базы данных:** управление базами GitHub и открытыми источниками в настройках.

## Обработка SID/STAR с цифрами

Принимаются аэропорты с суффиксом ВПП, например `UUEE24C`, `FSIA31`. Если сразу после вылета или перед прилётом встречается **неизвестный буквенно-цифровой** идентификатор терминальной процедуры (например, `DEMO2A`, `ARR9C`), он пропускается при визуализации. `DCT` и обозначения ATS при этом не мешают обнаружить процедуру. Известные в базе FIX с цифрами и ICAO-координаты **не пропускаются**; неизвестный FIX в середине маршрута по-прежнему вызывает разрыв. Это только схематичное соединение подтверждённых точек, **не** восстановление реальной геометрии SID/STAR.

## GPX

- GPX 1.1 с именами FIX сразу в `<rtept><name>` и в дополнительных `<wpt><name>` для совместимости с импортёрами. Пользовательские именованные точки и их координаты — только из подтверждённой базы/ввода.
- Фактическое отображение имён вместо номеров **зависит от Windy**: встроенный планировщик может самостоятельно перенумеровать точки даже при наличии `<name>`.
- Время ETD записывается в `<fr:plannedDepartureUtc>` и в описание файла. Времена прохода точек не придумываются. Windy может не импортировать ETD в своё поле автоматически.
- Для неполного маршрута сохраняются отдельные подтверждённые участки, без соединения через неизвестный FIX; имя файла содержит `PARTIAL`.
- «Скачать GPX» на совместимом iPad открывает системное меню «Поделиться» → «Сохранить в Файлы». В остальных браузерах используется скачивание.

Нет: метеопланировщика, погодных таблиц, выбора погодных слоёв, загрузки Open-Meteo/Windy forecast, PDF/HTML-отчётов, Vercel API. Отдельного платного погодного ключа не требуется. Секрет `WINDY_API_KEY` в GitHub используется только при публикации самого плагина.
