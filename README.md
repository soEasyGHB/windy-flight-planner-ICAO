# Windy Flight Route Analyzer — 1.2

**Версия для Windy: `1.2.0`.** Чистый исходный проект плагина. В этом релизе нет материалов старых версий, собранных временных тестовых файлов и неиспользуемого метеопланировщика.

## Основной сценарий

1. Вставь маршрут ICAO/OFP в увеличенное поле ввода и нажми «Построить маршрут».
2. Выбери дату и время вылета **UTC** (поля расположены по центру друг под другом).
3. Нажми **«1. Сформировать ссылку с UTC»** и проверь показанную строку «Выбрано» / «В URL Windy».
4. Нажми **«2. Открыть готовую ссылку в Windy»**, либо скопируй ссылку и открой её в Safari. Это обычный переход на `/route-planner/ifr/...?...`, который был проверен пользователем на примере маршрута UUEE–UNNT.
5. Кнопка **«Скачать GPX»** сохраняет GPX в браузере или вызывает системное меню «Поделиться» на iPad.

Проверенный формат URL:
`https://www.windy.com/route-planner/ifr/55.9726,37.4146;55.0126,82.6507?2026-11-16-18`

**Ограничение времени:** в проверенном варианте ссылки Windy используется трёхчасовой временной слот, а в GPX сохраняется исходное точное UTC, включая минуты. Перед открытием ссылки всегда можно проверить фактически отправляемый слот. После изменения времени ссылка становится недействительной до повторного формирования.

## Что сохранено

- Разбор маршрута OFP/ICAO, базовая визуализация на карте и подписи распознанных FIX.
- Пропуск нераспознанных SID/STAR с цифрами около аэропортов, без ложного соединения пробелов в середине маршрута.
- GPX с именем по аэропортам (`UUEE-UNNT.gpx`), с именованными `rtept` и `wpt` и точным временем UTC на вылете. Windy может отображать номера вместо имён по собственным правилам импорта.
- Неполный маршрут отмечается как `-PARTIAL` и не соединяется через неизвестные точки.
- В настройках только «Ошибки и предупреждения» и «Навигационные базы данных».
- GitHub Actions для сборки/публикации и для ручного либо автоматического обновления навигационных файлов.

Нет офлайн-HTML/PDF, отдельной метеотаблицы, Open-Meteo, Vercel, погодных слоёв и устаревших процедур.

## Установка и очистка GitHub

Смотри [INSTALL-v1.2.md](INSTALL-v1.2.md). В репозитории можно применить `npm run cleanup:legacy`, удаляющую старые файлы проекта, **но сохраняющую** `navdata-input/` и `public/navdata/` (включая уже опубликованные данные).

## Проверки

`npm run test:release` — обязательные тесты, проверка конфигурации, реальная сборка Rollup/Svelte и проверка результата `dist`. Отсутствие доступа к npm registry в среде подготовки не позволило подтвердить полную сборку; **не публикуйте**, пока проверка в Codespaces не прошла.

Этот плагин — вспомогательная визуализация и не предназначен для эксплуатационного планирования, аэронавигационного обеспечения или замены официальных документов.
