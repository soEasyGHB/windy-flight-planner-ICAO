# Windy Flight Route Analyzer — версия 1.1.2

Минималистичный плагин для отображения маршрутов OFP/ICAO на карте Windy, экспорта GPX и открытия штатного IFR-планировщика через URL.

## Что изменено в версии 1.1.2

Ссылка теперь формируется **отдельной кнопкой**, а не изменяется в момент открытия нового окна — это специально сделано для диагностики проблем с датой/временем на iPad Safari.

1. Построй маршрут с подтверждёнными навигационными точками.
2. Выбери дату и время вылета **UTC** в двух полях.
3. Нажми **«1. Сформировать ссылку с UTC»**. Плагин прочитает реальные значения обоих полей прямо из DOM.
4. Посмотри строку **«Выбрано»** и фактическое **«В URL Windy»**. Ниже появится полный URL, который можно выделить и скопировать.
5. Нажми **«2. Открыть готовую ссылку в Windy»**. Это обычная ссылка, использующая тот же формат, что сработал в ручном тесте.
6. При проблемах нажми **«Скопировать URL»** и вставь его в адресную строку Safari. Так можно проверить отдельно сам URL и поведение Windy при открытии из плагина.

**Важно:** выбранный ETD может иметь минуты, но URL штатного планировщика в протестированном формате содержит трёхчасовой интервал. Например, 18:20 UTC преобразуется в URL с `...-18`, а 20:00 — с `...-21`. Это явно видно в предварительном просмотре. В GPX остаётся **точное** UTC.

Пример протестированного формата:
`https://www.windy.com/route-planner/ifr/55.9726,37.4146;55.0126,82.6507?2026-11-16-18`

Если дата или время изменены после формирования ссылки, **готовый URL сбрасывается**. Его необходимо сформировать снова. Это предотвращает открытие маршрута со старым временем.

## Остальные функции

- Ввод ICAO/OFP с полем на 8 строк, построение/очистка и подписи известных FIX на карте.
- Скачивание GPX либо системное «Поделиться» на iPad; имя по аэропортам (`UUEE-UNNT.gpx`), а при частичном маршруте добавляется `-PARTIAL`.
- Запись точного ETD в GPX, имён навигационных точек в `rtept` и `wpt`; штатный Windy может показывать вместо имён номера.
- Предупреждение о неизвестных точках и разрывах; SID/STAR с цифрами около аэродромов пропускаются, если их геометрия неизвестна.
- В настройках остаются только «Ошибки и предупреждения» и «Навигационные базы данных».

Отдельного метеопланировщика, Open-Meteo, Vercel, экспорта HTML/PDF и управления погодными слоями нет. `WINDY_API_KEY` нужен только для публикации плагина. Не использовать для официального навигационного планирования.
