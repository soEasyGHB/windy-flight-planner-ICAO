# Windy Flight Route Analyzer — 1.2.3

Плагин Windy для визуализации маршрутов ICAO/OFP, экспорта именованного GPX и открытия штатного IFR-планировщика по сформированной ссылке.

## Интерфейс

- **Ввод маршрута:** увеличенное поле OFP/ICAO, кнопки построения и очистки маршрута.
- **Планировщик полёта:** компактные поля даты и времени UTC (по центру друг под другом), кнопка **«Скачать GPX»**, кнопка **«Сформировать план»** и появляющаяся после формирования ссылка **«Открыть планировщик»**.
- После построения маршрута и нажатия **«Сформировать план»** плагин формирует URL `/route-planner/ifr/…?...`, который можно открыть кнопкой **«Открыть планировщик»**. При изменении маршрута или UTC ссылка сбрасывается и требуется повторное формирование.
- При подготовке ссылки указанное UTC **округляется до ближайшего целого часа**: 05:01 → 05:00; 05:31 → 06:00; 23:40 → 00:00 следующего дня. Только интервалы 00/03/06/09/12/15/18/21 официально описаны для публичных URL Windy; произвольные часы не гарантируются. В GPX сохраняется точное время с минутами.
- Экспериментальный механизм точного UTC через `@windy/store`, `redrawFinished` и внутренний `rplanner` **полностью удалён** вместе с кнопкой и неиспользуемыми тестами.
- Показанные дата/время вводятся в нативные поля браузера; их текст выравнивается по центру, размеры уменьшены до ширины 170 px и высоты 34 px.

## Остальные функции

- Отображение подписанных FIX и трасс на карте; обработка SID/STAR рядом с аэропортами.
- GPX с именами аэропортов и FIX, файлом вида `UUEE-UNNT.gpx`, точным UTC и меню «Поделиться/Сохранить в Файлы» на iPad.
- В настройках остались только разделы «Ошибки и предупреждения» и «Навигационные базы данных».
- Нет офлайн-HTML/PDF, таблицы метеопланировщика, Vercel или ключей API погоды.

## Установка

См. [INSTALL-v1.2.3.md](INSTALL-v1.2.3.md). После распаковки запускай `npm install --no-audit --no-fund` и `npm run test:release` в Codespaces. Публикуй только после успешной полной сборки.

**Плагин предназначен для справочной визуализации, а не для эксплуатационной IFR-навигации.**
