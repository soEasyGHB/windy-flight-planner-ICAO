# Windy Flight Route Analyzer — 1.2.2

Чистый исходный проект плагина Windy для визуализации маршрутов ICAO/OFP, экспорта именованного GPX и экспериментальной передачи маршрута в штатный IFR-планировщик.

## Две кнопки для передачи времени UTC

После построения маршрута и выбора даты/времени UTC:

1. **«1. Сформировать URL (ближайший час)»** округляет выбранное время до ближайшего полного UTC-часа и показывает ссылку `/route-planner/ifr/...?...`. Нажми **«Открыть готовую ссылку в Windy»**, чтобы открыть её обычным переходом в Safari. Примеры: 05:01 → 05:00; 05:31 → 06:00; 23:40 → 00:00 **следующего дня**. Это тест **почасового** параметра `YYYY-MM-DD-HH`, а НЕ гарантированная поддержка произвольных часов в Windy. В официальной документации Windy для URL указаны только трёхчасовые UTC-слоты (`00, 03, 06, 09, 12, 15, 18, 21`). Для остальных часов Windy вправе игнорировать URL-время. Рабочий проверенный пользователем маршрут на 18:00 остаётся совместимым.

2. **«2. Точное UTC через API (эксперимент)»** в текущей вкладке устанавливает точное время через документированный `@windy/store`, проверяет фактически принятое значение, ожидает `redrawFinished` (не более пяти секунд) и отправляет подтверждённые координаты событием открытия внутреннего планировщика `rplanner`. Этот вызов **не является официальным API установки ETD Route Planner**. Время карты может установиться правильно, но штатный планировщик всё ещё может использовать другое время. Смотри диагностический статус и проверь ETD вручную.

Кнопка «Скопировать URL» удалена. Сам текст URL остаётся видимым и может быть выбран вручную. При изменении ETD/маршрута ранее сформированная ссылка очищается. В отдельном GPX всегда сохраняется **точное** UTC вылета без округления.

## Остальные функции

- Ввод маршрута ICAO/OFP, отображение точек и трасс, подписи FIX на карте.
- Пропуск неизвестных SID/STAR с цифрами возле аэропортов без выдуманных связей через неизвестные FIX посреди маршрута.
- GPX с названиями аэропортов и FIX, именем `UUEE-UNNT.gpx` (или `-PARTIAL`) и исходным ETD UTC. В iPad кнопка «Скачать GPX» использует меню «Поделиться / Сохранить в Файлы».
- В настройках только «Ошибки и предупреждения» и «Навигационные базы данных». CSV/AIRAC в `navdata-input/` и `public/navdata/` при обновлении не удаляются.
- Нет прежних метеотаблиц, офлайн-HTML/PDF, Vercel и API-ключей погоды.

## Установка и проверка

См. [INSTALL-v1.2.2.md](INSTALL-v1.2.2.md). После распаковки, до публикации, запусти `npm install --no-audit --no-fund` и `npm run test:release` в Codespaces. При неуспешной компиляции не публикуй релиз.

**Предупреждение:** плагин — справочный визуализатор, не официальный источник навигационной или метеорологической информации для выполнения полёта.
