# Windy Flight Route Analyzer — версия 1.0.1

Минималистичный плагин для визуализации проверенных точек OFP/ICAO на карте Windy, экспорта GPX и открытия штатного планировщика Windy.

## Интерфейс

- **Ввод маршрута:** построение/очистка маршрута, подписи подтверждённых FIX на карте.
- **Планировщик полёта:** дата и время UTC друг под другом по центру, «Скачать GPX» (меню «Поделиться» на iPad, обычное скачивание при отсутствии поддержки) и «Открыть штатный планировщик Windy». При открытии передаётся **только время на общую шкалу прогноза Windy**; сам маршрут, TAS и FL не передаются. Время старта непосредственно в штатном планировщике **надо проверять**.
- **Настройки:** только «Ошибки и предупреждения» и «Навигационные базы данных»; сообщения о частичном GPX видны только в диагностике.

## GPX

- **Имя файла:** при наличии двух подтверждённых аэропортов ICAO — `UUEE-UNNT.gpx`, `USSS-LTAI.gpx`. Суффикс ВПП (`UUEE24C`, `UNNT25`) отбрасывается. Для неполного маршрута добавляется `-PARTIAL`, например `UUEE-UNNT-PARTIAL.gpx`; если невозможно однозначно установить аэропорты, используется `windy-route.gpx` или `windy-route-PARTIAL.gpx`.
- **Время:** выбранный ETD UTC записывается как стандартный `<time>` **только на первую точку маршрута** (и её `<wpt>`, если подтверждена исходная точка), а также в `<fr:plannedDepartureUtc>` и читаемое описание. Время прохождения остальных FIX не выдумывается. Метаданные `<metadata><time>` не подменяются временем вылета.
- **Названия:** у каждой экспортируемой именованной точки есть `<name>`, `<cmt>`, `<desc>` как в `<rtept>`, так и в `<wpt>`. **Windy может отображать номера вместо имён**: это поведение интерфейса импортёра, которое невозможно гарантированно изменить содержимым GPX. В Windy Community зарегистрированы сообщения о пропаже имён точек при импорте в 2026 году.
- **Безопасность:** SID/STAR с цифрами около аэродромов пропускаются, если их геометрия неизвестна, неизвестный FIX в середине маршрута создаёт разрыв; неподтверждённые участки нельзя соединять вымышленными прямыми. GPX служит только для визуализации.

## Установка и проверки

Пошаговая установка: [INSTALL-v1.0.1.md](INSTALL-v1.0.1.md). Результаты тестирования: [AUDIT-v1.0.1.md](AUDIT-v1.0.1.md).

В проекте нет погодных API, Vercel, PDF/HTML-отчётов и отдельного метеопланировщика. `WINDY_API_KEY` используется только для публикации плагина. Не использовать для официального планирования IFR или навигации.
