# Windy Flight Route Analyzer v0.11.1 — GPX & навигационная база

Упрощённый плагин Windy для отображения маршрута ICAO/OFP на карте и экспорта GPX. **Никаких метеотаблиц, графиков FL, выбора слоя погоды, HTML/PDF-отчётов или API Windy/Open-Meteo здесь нет.** Плагин не переключает текущий погодный слой Windy.

## Интерфейс

- **Ввод маршрута**: текст ICAO/OFP, «Построить маршрут», «Очистить». На карте — только подтверждённые участки и имена FIX/аэропортов.
- **Планировщик полёта**: **«Скачать GPX»** (системное меню «Поделиться» на iPad, скачивание при отсутствии поддержки) и **«Открыть штатный планировщик Windy»** (только открытие, без передачи маршрута и параметров). GPX готовится сразу при построении и не зависит от сети. Системное меню iPad позволяет выбрать «Сохранить в Файлы». При разрывах имя файла содержит `PARTIAL`; неподтверждённые отрезки не соединяются.
- **Настройки → Ошибки и предупреждения**: переключатель детализации, статус, неизвестные/неоднозначные FIX, разрывы, координаты.
- **Настройки → Навигационные базы данных**: статус AIRAC, обновление из публичного GitHub, переход к синхронизации Google Drive и загрузке ZIP.

Плагин не заменяет сертифицированную аэронавигационную информацию. Данные используются для визуализации.

## Установка

См. [`INSTALL-v0.11.1.md`](INSTALL-v0.11.1.md). Комплект кода: `src/plugin.svelte`, `src/navdb.ts`, `src/xplane.ts`, `src/routeGpx.ts`, `src/gpxDownload.ts`, настройки сборки и workflows GitHub. Навигационные данные третьих лиц не включены.

```bash
npm run cleanup:legacy
npm install --no-audit --no-fund
npm run test:release
```

Публикация через GitHub Actions `publish-plugin` после успешной проверки. Для публикации необходим GitHub Secret `WINDY_API_KEY` (ключ публикации **плагина**, не прогнозный ключ); Vercel не нужен.
