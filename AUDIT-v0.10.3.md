# Аудит v0.10.3: исправление запуска Windy

## Причина отказа в v0.10.2

Файл `src/plugin.svelte`, инициализатор `pressuresDescending`, ссылался на отсутствующий идентификатор `WINDY_PRESSURES`. После миграции на Open-Meteo этот массив больше не экспортируется и не объявлен. Svelte-компонент при открытии вычислял инициализатор и падал с `ReferenceError` до отображения панели. Предыдущие тесты проверяли только отдельные TS-модули и текст Svelte, поэтому не обнаружили проблему выполнения.

## Исправления

- `src/plugin.svelte`: `WINDY_PRESSURES` заменён на корректный `PRESSURES`, который импортируется из `src/weather.ts`.
- Явно объявлена переменная `profileViz`, вычисляемая реактивно Svelte.
- Перехвачены ошибки `setWeatherLayer()` внутри `onopen`, а также объединена защищённая инициализация карты и демонстрационной базы в `onMount`.
- `tools/check-plugin-startup.mjs`: smoke-тест компилирует `<script lang="ts">` штатным `tsc`, проверяет необъявленные символы (с учётом предоставляемого Windy `L`), исполняет инициализаторы в тестовом контексте, вызывает `onopen` с нормальным и отказавшим Windy store; негативная мутация воспроизводит исходный `WINDY_PRESSURES` и проверяет, что тест её обнаружит.
- Новый smoke-тест включён в `npm test`, а значит и в `test:release` и GitHub Actions `publish-plugin`.
- Версии `package.json` и `src/pluginConfig.ts` синхронизированы: `0.10.3`.

## Режим данных сохранён

- Таблицы Open-Meteo NOAA GFS без ключа и без Vercel.
- График ISA, тропопауза, ветровые рекомендации чётных/нечётных эшелонов, GPX, сохранение ETD и взаимодействие с Windy.

## Проверка

- `npm run check:tree`, `check:build-config`, `check:imports`, `check:exports` — предусмотрены и пройдены локально.
- `npm run typecheck:core`, `npm test`, включая `npm run check:startup` — предусмотрены и пройдены локально.
- `npm run build` здесь возвращает код 127: `sh: 1: rollup: not found`. Npm-зависимости Rollup/Svelte не установлены; **не заявляем**, что реальная сборка пройдена. `npm run verify:release` без сборки не может подтвердить артефакты.
- Для успешного релиза Codespaces/Actions обязательно должен выполнить `npm run test:release`.
- ZIP сформирован из полного дерева источников без `tests/generated`, `dist`, `node_modules`. CRC и SHA-256 проверяются при упаковке.

## Ограничение подтверждения

Проверен код и моделирование запуска Svelte script. Проверить **живой приватный плагин в пользовательском аккаунте Windy** невозможно без установленного экземпляра/доступа. Не следует приравнивать локальные тесты к подтверждению публикации и открытия в веб-приложении.
