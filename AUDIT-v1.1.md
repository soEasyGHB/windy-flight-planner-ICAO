# Аудит Windy Flight Route Analyzer — версия 1.1 (npm 1.1.0)

## Изменения относительно v1.0.3

- Удалены кнопка «Открыть штатный планировщик Windy» (без маршрута), `openNativePlanner` и более не используемый импорт `@windy/store`.
- Рабочая ссылка `/route-planner/ifr/lat,lon;...?YYYY-MM-DD-HH` сохранена без изменений. GPX и UTC, парсер OFP/ICAO, подписи FIX и навигационные базы сохранены.
- Текстовое поле маршрута увеличено с 4 до 8 строк; минимальная высота с 86 до 172 px.
- Уменьшена высота нативных полей даты и времени с 42 до 28 px, уменьшены отступы и подписи. Суммарная высота каждой строки поля с подписью около 44 px — как у основных кнопок. Вертикальная колонка и центрирование сохранены.
- Обновлены проверки интерфейса и запуска, документация и версия в `package.json`/`pluginConfig.ts`.

## Проверки

См. фактические результаты запуска в текущем окружении. Полная сборка Rollup/Svelte требует `npm install` и `npm run test:release` в GitHub Codespaces при наличии сетевого доступа к npm registry. Работа нативных полей даты/времени на конкретном iPad требует визуальной проверки после публикации.

### Результаты локальных запусков

Успешно:

- `npm run check:tree` — все необходимые исходники, версии совпадают, устаревших модулей нет;
- `npm run check:build-config`, `npm run check:imports`, `npm run check:exports`;
- `npm run test:layout` — удаление пустого планировщика, 8 строк маршрута и компактные поля UTC;
- `npm run typecheck:core` — ошибок нет;
- `npm test` — парсер маршрута, GPX, навигационные базы, пользовательский URL Windy и имитация запуска Svelte.

Не подтверждено: `npm run build` — `sh: rollup: not found` (нет установленных npm-зависимостей). Известный рабочий URL не менялся. В реальном Windy и на iPad обновлённый макет ещё не проверялся. Сначала необходимо запустить `npm install --no-audit --no-fund && npm run test:release` в Codespaces.
