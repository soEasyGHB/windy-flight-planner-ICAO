# Проверка релиза Windy Flight Route Analyzer v0.9.3

Основа: полный исходный проект v0.9.2. Это полная сборка исходников, а не отдельный HOTFIX.

## Изменения

- В `src/profileChart.ts` фильтруются компоненты `kind: 'cross'`, то есть округлённая до нуля продольная составляющая, включая безветрие.
- Нет стрелок и `0` на графике для бокового/отсутствующего ветра. В выбранной точке вместо нуля или отсутствующего значения — небольшой прочерк.
- Для попутной/встречной продольной составляющей сохранены зелёная/красная стрелки и величина без знака `+`/`−` и без `kt`.
- Интерполяция в профиле не подставляет ветер с соседнего FIX, если у одного из концов участка данных нет.
- В сводной строке и подписи tooltip не выводятся знаки и единицы продольной составляющей. Знаки ISA deviation остаются корректными.
- Сохранены FL330–FL390, выделение FL360, температурная заливка ISA, диагностическая тропопауза, экспорт GPX, навигационная база и сохранение ввода.

## Контроль

`npm run check:tree`, `check:imports`, `check:exports`, `typecheck:core`, `npm test` и проверка полной сборки ZIP после распаковки.

Окончательная сборка `npm run build` в Codespaces обязательна до публикации Windy.
