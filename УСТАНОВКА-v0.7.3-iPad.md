# Обновление Windy Flight Route Analyzer v0.7.3 с iPad

Загрузи `Windy-Flight-Route-Analyzer-UPDATE-v0.7.3.zip` в **корень** рабочего Codespaces.

В терминале убедись, что нет незаконченного rebase/merge (`git status`). Если рабочее дерево чистое, выполните:

```bash
git pull --ff-only origin main
unzip -o Windy-Flight-Route-Analyzer-UPDATE-v0.7.3.zip
npm run typecheck:core
npm test
npm run build
```

При успешных проверках:

```bash
git add src/routePlanner.ts src/plugin.svelte src/pluginConfig.ts package.json tests/test_route_planner.mjs README.md УСТАНОВКА-v0.7.3-iPad.md
git commit -m "Add safe partial GPX and route diagnostics v0.7.3"
git push origin main
```

Затем GitHub → Actions → publish-plugin → Run workflow.

**Если есть конфликт, ошибка сборки или `git push`, не делай force push.** Пришли текст ошибки.

### Поведение экспорта

Если маршрут полностью распознан — обычный GPX и Windy Route Planner. Если не распознан — GPX состоит только из отдельных проверенных участков, а Route Planner получает только самый длинный непрерывный участок. Рядом с кнопками видны причины неполноты. Для неоднозначных FIX предусмотрено отдельное осознанное подтверждение координат. Никогда не используй такую карту для оперативной IFR-навигации.
