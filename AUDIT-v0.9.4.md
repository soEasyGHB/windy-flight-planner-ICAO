# Проверка полного Windy Flight Route Analyzer v0.9.4

**Исходная база:** полный v0.9.3.

## Изменения

1. Убраны нижняя легенда и левая информационная колонка графического профиля. Внизу вместо легенды — ETD UTC, расстояние, расчётная длительность, FL, TAS и сводка тропопаузы.
2. В основном меню под датой и временем возвращено поле FL330–390 с шагом 10, значение по умолчанию FL360. Выбор сохраняется в localStorage вместе с OFP и ETD. TAS остаётся 450 kt.
3. Профиль теперь всегда выводит полные названия всех FIX. Подписи распределяются по нескольким строкам и связываются с истинной координатой на оси расстояния.
4. График тропопаузы пересекается с границами FL330–390 корректно: видимые участки отображаются, за диапазоном пишется «выше/ниже». Отсутствующая оценка не подменяется фиктивной линией.
5. Сохранены маршруты/GPX без трасс, зелёные/красные продольные компоненты ветра без знаков и kt, цвета ISA, сохранение данных, скрытые настройки, Google Drive → GitHub и HTML/PDF.

## Проверка

- `npm run check:tree`, `check:imports`, `check:exports`, `typecheck:core`, `npm test` — обязательны.
- `npm run build`, `npm run verify:release` — выполняются в Codespaces до публикации.
- Тест `test_profile_ui_v094.mjs` проверяет восстановленный FL, нижнюю строку, все подписи FIX и тропопаузу.
- Пакет `v0.9.4` не включает приватные/лицензируемые AIRAC CSV и не заменяет опубликованную базу.

## Ограничения

Расстояние между FIX приблизительное, TAS не скорректирована ветром, и расчётная длительность не равна прогнозной фактической длительности. Тропопауза — грубая модельная оценка, не официальный SIGWX. Если она находится вне FL330–390 или модель не возвращает достаточных данных, на разрезе нельзя честно показать её линию внутри этого диапазона.
