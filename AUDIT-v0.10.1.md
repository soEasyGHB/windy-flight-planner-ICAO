# Отчёт о сборке и целостности v0.10.1

## Найденная проблема

Предыдущая версия **v0.10.0** никогда не проходила настоящую сборку Rollup в среде подготовки, хотя это критичный этап. Настройка `@rollup/plugin-node-resolve` не содержала `.ts` в списке расширений. Его документированные расширения по умолчанию: `.mjs`, `.js`, `.json`, `.node`. Из `src/plugin.svelte` импортируются локальные модули TypeScript без расширения. После исправления подключены `.ts`, `.tsx` и `.svelte`. Также был пропущен `dist/package.json` (официальный шаблон Windy его копирует).

## Что проверяется

- Проверка полноты исходников и согласованности версий `check:tree`.
- Статический контроль конфигурации сборки `check:build-config`.
- Импорты и экспорты TypeScript-модулей `check:imports`, `check:exports`.
- TypeScript-модули `typecheck:core`.
- Полный локальный набор тестов `npm test`.
- **В Codespaces/GitHub Actions**: реальная сборка `npm run build` и проверка готового архива публикации `verify:release`.
- ZIP: проверка распаковки, уникальности имён и SHA-256.

## Ограничения проверки в среде подготовки

`npm install` не завершается из-за DNS-ошибки `EAI_AGAIN registry.npmjs.org`. Поэтому **реальная компиляция Rollup/Svelte и загрузка Windy не могут быть честно подтверждены в этой среде**. Статические проверки и тесты на установленном системном TypeScript запускаются здесь; `npm run test:release` должен быть выполнен в Codespaces, где установлен интернет-доступ к npm. Без лога исходной ошибки нельзя подтвердить, что других проблем компиляции нет.

## Сохранение функционала

Полный исходный архив v0.10.0 использован без удаления функций для GPX, Open-Meteo (тропопауза), Windy GFS, ISA, FL, Vercel API, GitHub workflows и навигационной базы. Все новые изменения ограничены обработкой сборки, CI, версиями, проверками и документацией.
