# Аудит Windy Flight Route Analyzer 2.0

## Изменения относительно v1.2.3

- **Нативные поля даты и времени:** CSS `display:flex; align-items:center; justify-content:center` для элемента и внутренних WebKit-подэлементов. Высота осталась 34 px, ширина 170 px. Нативный браузерный date/time picker сохранён.
- **Навигационные базы:** удалены только кнопки синхронизации Google Drive и загрузки GitHub, а также неиспользуемые обработчики в Svelte. Процессы GitHub Actions и конвертор AIRAC не изменены. Пользовательская инструкция теперь указывает только папку Google Drive `Windy-NAVDATA`, архив `navdata.zip` и три файла одного цикла AIRAC.
- **Подпись маршрута:** «Маршрут из OFP».
- **IFR/Airspeed:** действующий URL уже содержит `/route-planner/ifr/`. Подтверждённого документированного способа включить Airspeed через URL/Plugin API не найдено. Во избежание нестабильной автоматизации ничего не добавлено.
- **Версия:** `2.0.1` в npm и плагине Windy. Старые документы не входят в чистый архив.

## Проверка

**ПРОЙДЕНО:** `npm run check:tree`, `npm run check:build-config`, `npm run check:imports`, `npm run check:exports`, `npm run typecheck:core`, `npm test` (маршруты, GPX/XML, геометрия, AIRAC, URL, имитация открытия компонента).

**Визуальная проверка:** нативные `date`/`time` отрисованы в Chromium с высотой 34 px и центрированием текста; реальное iPad/Safari не проверено.

**НЕ ВЫПОЛНЕНО:** полная сборка `npm run build`. `npm install` останавливается на сетевой ошибке `EAI_AGAIN` при обращении к npm registry, поэтому `rollup: not found`. В ZIP не включены выдуманные готовые build-артефакты.

Полная Svelte/Rollup-сборка должна быть выполнена в Codespaces командой `npm run test:release`. Работа нативных picker на iPad, Windy IFR и Airspeed могут требовать ручной проверки в браузере.

**Примечание:** точность и актуальность навигационных данных должны быть проверены пользователем. Не применять этот инструмент для эксплуатационной навигации.

## Дополнение 2.0.1: пользовательский интерфейс навигационной базы

- В пользовательской панели больше нет ссылок на технические каталоги и инструменты загрузки.
- Указаны реальная папка Google Drive `Windy-NAVDATA`, архив `navdata.zip` и три файла `earth_fix.dat`, `earth_nav.dat`, `earth_awy.dat` одного AIRAC.
- Текущие обработчики чтения навигационной базы, workflow синхронизации, GPX и URL-планировщика оставлены без изменения.
- Ссылка Google Drive проверена по подключённому каталогу: в папке находится один `navdata.zip`. Само выполнение фоновой синхронизации не проверено.
