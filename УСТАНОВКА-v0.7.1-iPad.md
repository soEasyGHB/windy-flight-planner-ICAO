# Обновление v0.7.1 на iPad

1. Скачайте ZIP **UPDATE-v0.7.1** в «Файлы» и загрузите в **корень** Codespaces.
2. Убедитесь, что нет незавершённого merge/rebase: `git status`.
3. Выполните команды по порядку:

```bash
git pull --ff-only origin main
unzip -o Windy-Flight-Route-Analyzer-UPDATE-v0.7.1.zip
npm install
npm run typecheck:core
npm test
npm run build
```

4. Если всё завершилось без ошибок:

```bash
git add src/plugin.svelte src/routePlanner.ts src/pluginConfig.ts package.json tests/test_route_planner.mjs README.md УСТАНОВКА-v0.7.1-iPad.md
git commit -m "Add Windy Route Planner button v0.7.1"
git push origin main
```

5. **GitHub → Actions → publish-plugin → Run workflow**. Затем откройте Windy и постройте подтверждённый маршрут.
6. Нажмите **«Открыть в Windy Route Planner»**. Если URL-импорт в приложении не сработает — вернитесь в плагин, скачайте GPX и импортируйте через **Distance & Planning → More → Import GPX**.

Важное: передача URL не программирует скорость/время вылета или IFR-режим штатного планировщика: их нужно установить там вручную. Данные и автоматическое обновление Google Drive → GitHub не меняются.
