# Аудит полной версии 0.8.5

## Исправлено

1. Версии `package.json` и `src/pluginConfig.ts` синхронизированы: `0.8.5`.
2. Тесты `test_ui_layout.mjs` и `test_clean_ui.mjs` обновлены под четыре серых блока, вертикальные поля даты/времени, ровно четыре погодных слоя и скрытые настройки.
3. В начале и в конце строки маршрута `UUEE24C` и `OMDB30R` нормализуются в ICAO-коды аэропортов. Посередине строки похожие токены автоматически не меняются.
4. GPX содержит только именованные точки OFP как GPX `<rtept>`; синтетические вершины воздушных трасс `<trkpt>` больше не выдаются. При неполных маршрутах подтверждённые части остаются раздельными. Возможности импорта `<rte>` надо проверить в конкретном клиенте Windy.
5. Добавлен интеграционный тест конвертации `earth_awy.dat` X-Plane 11/12 на синтетической трассе `Y12` и проверка AIRAC.
6. GitHub Actions запускает Python 3.12 и проверку полного дерева перед тестами и публикацией.
7. Полный ZIP содержит файлы в корне архива, без лишнего вложенного каталога.

- `npm run check:tree` — наличие 28 ключевых файлов и совпадение версий.

- `npm run typecheck:core` — строгий TypeScript для логических модулей.

## Что не подтверждено в среде подготовки

- `npm install` — недоступен `registry.npmjs.org` (DNS `EAI_AGAIN`).
- Реальный `npm run build` с Rollup/Svelte/Windy SDK и работа интерфейса на iPad **не подтверждены**.
- Полная реальная трасса `Y12` зависит от актуальности и состава загруженной навигационной базы (в ZIP нет пользовательских AIRAC-данных).
- Windy GPX importer и внутренний Route Planner должны быть проверены на действующей версии Windy.

Не публикуйте, если `npm run build` или `npm run verify:release` завершились ошибкой.

Проект не предназначен для оперативной навигации, принятия решений по маршруту или официального метеобрифинга.
