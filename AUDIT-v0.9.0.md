# Технический аудит полного проекта v0.9.0

## База

Взята полная v0.8.6. Сохранены предыдущие функции: четыре главных блока и скрытые настройки, маршруты по именованным FIX без ATS, GPX только по именованным FIX, распознавание полосы аэродрома `UUEE24C → UUEE`, локальное сохранение OFP/ETD, TAS 450 kt, FL360, начальный слой «Грозы», Google Drive → GitHub navdata, офлайн-HTML/PDF.

## Новый реальный профиль

- `src/profileChart.ts` — независимый модуль геометрии и расчётов SVG-профиля.
- `src/plugin.svelte` — вместо табличного блока нижнего профиля использует SVG-график с горизонтальной осью расстояния NM и вертикальной осью FL330–390.
- Флюгеры метеорологического направления ветра («откуда»), скорость в 5/10/50 kt, спокойный ветер кружком; интерполяция вектора по расстоянию.
- Цветные горизонтальные полосы заполнены градиентом ISA Δ°C из данных каждой именованной точки; подписи отдельных изолиний ISA ориентировочные.
- FL360 отмечен синей линией с кружками в точках маршрута. Точки являются активными кнопками для переключения времени Windy по ETA.
- В выделенной строке сведений показаны фактическая температура, ISA Δ°C и ветер для выбранной точки на FL360.
- Тропопауза рисуется отдельными пунктирными участками **только при данных в FL330–390**. Отсутствующие значения или значения за диапазоном не прижимаются к краю графика и не соединяются через пробелы.
- Таблицы FL300–FL400 внутри «Настроек» не затронуты.

## Тесты

- `npm run check:tree` — наличие основных файлов, совпадение номера версии и импортов.
- `npm run check:imports` — локальные импорты файлов.
- `npm run check:exports` — наличие именованных экспортов.
- `npm run typecheck:core` — строгая проверка TypeScript модулей.
- `npm test` — сценарии навигации, GPX, прогноза, интерфейса и отдельные проверки вертикального профиля `tests/test_profile_chart_v090.mjs`.
- Проверка итогового ZIP — независимая распаковка в пустой каталог и повторные тесты.

**Ограничение:** Svelte/Windy/Rollup не установлены в текущем окружении, так как npm registry недоступен (`EAI_AGAIN`). Поэтому итоговая публикационная сборка должна пройти в Codespaces: `npm install`, `npm run build`, `npm run verify:release`.

## Источник и применимость

Метеопараметры берутся из Open-Meteo и интерполируются по давлению. Тропопауза — приблизительная диагностическая оценка по ограниченному числу уровней, не продукт SIGWX. Расстояния и ETA приблизительные и не заменяют аэродромную/маршрутную документацию или штатный расчёт OFP.
