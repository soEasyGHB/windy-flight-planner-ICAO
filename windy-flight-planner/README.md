# Windy Flight Route Analyzer — исходный код, v0.1.0

**Статус:** функциональный прототип / исходный проект, НЕ опубликован, НЕ проверен внутри реального Windy. Геометрия маршрута и разбор CSV протестированы локально; Svelte/Windy-сборка и вызовы метео-API требуют подключения к интернету в вашей среде разработки. **Не использовать как навигационный источник, для вылета, диспетчеризации или оценки эксплуатационных минимумов.**

## Что реализовано

1. Вставка маршрута с ICAO аэропортами, RNAV FIX, VOR/NDB и `DCT`; ручные координаты в формате `5230N03030E` / `N5230E03030`.
2. Нанесение найденных точек и соединяющей линии непосредственно на карту Windy.com; показ неизвестных/неоднозначных кодов.
3. Автозагрузка открытых каталогов `OurAirports airports.csv`, `OurAirports navaids.csv` и `euvl/aviation-waypoints` при открытии плагина. Их покрытие **не является** полноценной мировой актуальной IFR-базой.
4. Импорт собственных CSV `ident,latitude_deg,longitude_deg,type`, в том числе экспортированных из **лицензированной** базы ICAO.
5. Импорт CSV трасс `airway,segment,seq,latitude_deg,longitude_deg` и разворачивание трассы между известными точками, только если найден связный путь и есть совпадающие географически концы; непройденные ATS-трассы маркируются предупреждением. **Не валидируются доступность, направление, ограничения, тип RNP, эшелоны, специальные процедуры или AIRAC**.
6. Переключение встроенных погодных слоёв Windy (ветер, температура, влажность, турбулентность, обледенение, грозы и др.), ECMWF/GFS и ближайшего изобарического уровня к FL.
7. Отдельный запрос Open-Meteo: точки через ~250 NM (не больше 10), ETA по условной TAS (пока без ветра), метеотаблица на выбранном эшелоне, вертикальный разрез 850–150 hPa (T °C, ветер kt), экспорт CSV.
8. Иллюстративные индикаторы возможных условий обледенения (температура + RH), сильного ветра, высокого CAPE и больших перепадов скорости между уровнями — **это не SIGMET, не фактический прогноз CAT/обледенения**.

## Как запустить на компьютере (Windows / macOS / Linux)

Потребуются Node.js 20+ и npm, интернет, Google Chrome/Safari (браузер с доступом к windy.com) и учётная запись Windy.com.

```bash
# распаковать приложенный ZIP
cd windy-flight-planner
npm install
npm start
```

`npm install` скачает сборочные инструменты официального Windy Plugin Template (в `@windycom/plugin-devtools`). Откройте **https://localhost:9999/plugin.js** в браузере компьютера; при появлении предупреждения о локальном сертификате разрешите его для тестирования. Затем откройте **https://www.windy.com/developer-mode** и добавьте URL `https://localhost:9999/plugin.js`. Плагин должен открыться в правой панели.

Сборка для выпуска (без локального веб-сервера):

```bash
npm run build
```

Результат: `dist/plugin.js`, `dist/plugin.min.js` и вспомогательные файлы сборщика. Для публикации и подключения на iPad используйте **официальную инструкцию** https://docs.windy-plugins.com/getting-started/publishing-plugin.html . В архиве уже есть GitHub Actions workflow `.github/workflows/publish-plugin.yml`: разместите проект в вашем репозитории, получите ключ **Windy Plugins API** на https://api.windy.com/keys, запишите его как секрет репозитория `WINDY_API_KEY`, запустите workflow `publish-plugin` вручную. Ключ не следует присылать в чат. По умолчанию плагин `private: true`.

**Важно об iPad:** локальная ссылка `https://localhost:9999` на iPad НЕ подключается к серверу, запущенному на вашем компьютере. Для iPad удобнее однажды собрать/опубликовать приватный плагин через Windy, после чего открыть его в поддерживаемом клиенте. Проверка на мобильном устройстве ещё не проведена.

## Пример

После загрузки источников попробуйте:

```text
EHAM DCT EDDF DCT LTFM DCT OMDB
```

Впишите свой OFP-маршрут через пробел; формат без специальных изменений работает для ИМЕЮЩИХСЯ в базе идентификаторов. Если вставлены `SID/STAR` или непредставленные ATS-трассы, полётный путь будет неполным или неверным и интерфейс покажет предупреждение. Неподдерживаемые SPEED/LEVEL модификаторы пропускаются.

## Добавление данных ICAO Global Dataset

Лицензия ICAO — отдельная покупка. В архиве **нет** защищённой базы и её нельзя получить автоматически по обычной веб-ссылке: https://store.icao.int/en/airways-waypoints-navaids-dataset-one-time .

Если есть законно приобретённый экспорт ICAO в CSV:

```csv
ident,latitude_deg,longitude_deg,type
MYPNT,47.98765,23.45678,FIX
MYVOR,48.00000,23.50000,VOR
```

Загрузите CSV в разделе «Навигационная база». Для исходного GeoPackage (`.gpkg`) на компьютере с Python 3:

```bash
python -m pip install geopandas fiona shapely pyogrio
python tools/convert_icao_gpkg.py /path/to/licensed_icao.gpkg --output icao-export/
```

Затем загрузите сначала `icao-export/points.csv`, затем `icao-export/airways.csv` в интерфейсе плагина. Автоопределение столбцов и слоёв — **универсальная эвристика**, конвертер ещё НЕ проверен на файле ICAO и может потребовать указания `--ident-field` и `--airway-field` или коррекции под конкретную схему. Импорт GeoPackage **не** включает автоматически полноценную реконструкцию AIP-процедур, ограничений сегментов или навигационную валидацию.

## Тесты и ограничения

```bash
npm run typecheck:core
npm test
```

`npm test` запускает тесты локального парсера/расчёта геометрии/ATS-развёртки. Проверка внутри Windy и погодного API потребует внешнего интернета и доработок после первых запусков.

Важно: у Open-Meteo **бесплатный API только для некоммерческого использования**, с лимитами и обязательной атрибуцией (CC BY 4.0): https://open-meteo.com/en/terms . Прототип использует этот API только для дополнительной справочной оценки, а не метеоданные Windy или лицензированный авиабрифинг. Данные модели Open-Meteo и выбранный слой Windy могут отличаться.

### Что ещё нужно перед реальным использованием

- Полная легальная мировая IFR-база с обновлением AIRAC, навигационными идентификаторами, трассами и процедурами.
- Инструмент чтения OFP и разрешение неоднозначностей одинаковых идентификаторов по FIR/географии.
- Параметры перелёта с учётом реального профиля набора/снижения, forecast winds, TAS/GS и ETA.
- Проверенные источники SIGMET, существенных метеоявлений, воздушных пространств, NOTAM и AIP; классификация turbulence/icing по валидированным продуктам вместо простых эвристик.
- Полноценное тестирование Windy GL, мобильного iPad, CORS, лимитов API и производительности на глобальных базах.
