# Windy Flight Route Analyzer v0.8.1 — минималистичный интерфейс

Обновление пользовательского интерфейса поверх текущего v0.8.0. Погодная и маршрутная логика не меняется.

## Главная панель

На экране остаются только четыре основных блока:

1. Ввод маршрута (OFP/ICAO).
2. Данные полёта (ETD UTC, FL, TAS — по умолчанию 450 kt).
3. Слой погоды (грозы, осадки, турбулентность, радар и др.).
4. Планировщик и экспорт (Windy Route Planner, GPX, HTML, PDF, прогноз по точкам).

Под ними остаётся один закрытый раздел «Настройки». В нём вложенные сворачиваемые разделы: сообщения/ошибки/ограничения, ETA по точкам, диагностика маршрута, модель и высота, офлайн-снимок, таблицы FL300–FL400, навигационная база.

**Важно:** сообщения и предупреждения не удалены из кода и не подавлены. Они доступны в «Настройки» → «Сообщения, ошибки и ограничения»; диагностика подробностей — в «Настройки» → «Диагностика маршрута». При ошибке построения или экспорта проверяй эти разделы. Приложение предназначено только для предварительного обзора, не для официальных авиационных расчётов.

## Установка в GitHub Codespaces

1. Убедись, что нужные предыдущие исправления уже сохранены в репозитории.
2. Загрузи ZIP `Windy-Flight-Route-Analyzer-UPDATE-v0.8.1-CLEAN-UI.zip` в корень репозитория.
3. Выполни команды:

```bash
unzip -o Windy-Flight-Route-Analyzer-UPDATE-v0.8.1-CLEAN-UI.zip
npm run test:clean-ui
npm run test:layout
npm run typecheck:core
npm test
npm run build
```

4. До публикации проверь `dist/plugin.json` — версия должна быть `0.8.1`:

```bash
cat dist/plugin.json
```

5. Если все проверки успешны:

```bash
git add src/plugin.svelte src/pluginConfig.ts package.json tests/test_clean_ui.mjs tests/test_ui_layout.mjs INSTALL-v0.8.1-iPad.md
git commit -m "Simplify UI and hide diagnostics v0.8.1"
git push origin main
```

6. Запусти GitHub → Actions → `publish-plugin` → `Run workflow` на ветке `main`.

Если Windy ответит, что версия `0.8.1` уже существует, увеличь версию одновременно в `package.json` и `src/pluginConfig.ts`, пересобери и перепубликуй. Если build падает на импортах, убедись, что установлены и закоммичены исправления предыдущих версий.

## Список изменённых файлов

- `src/plugin.svelte` — переставлен HTML/Svelte интерфейс, добавлено оформление вложенных раскрывающихся групп. Логика `<script lang="ts">` оставлена *без изменений*.
- `src/pluginConfig.ts` — версия `0.8.1`.
- `package.json` — версия `0.8.1` и команда `test:clean-ui`.
- `tests/test_clean_ui.mjs` — проверка четырёх блоков, отсутствия сообщений на главном экране и сохранности кнопок.
- `tests/test_ui_layout.mjs` — обновлена ожидаемая версия.

Полная Rollup-сборка проверяется в Codespaces с зависимостями Windy.
