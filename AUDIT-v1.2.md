# Windy Flight Route Analyzer 1.2 — отчёт сборки и очистки

Версия проекта: **1.2.0**. Основа: сохранённый рабочий двухэтапный механизм формирования ссылки `/route-planner/ifr/`.

## Изменения

- Номер версии синхронизирован в `package.json` и `src/pluginConfig.ts`.
- Удалены документы прежних релизов, устаревшие и неиспользуемые модули, результаты предыдущих запусков тестов.
- Дополнена команда `npm run cleanup:legacy`, чтобы удалить накопившиеся файлы в старом репозитории, не трогая `navdata-input/` и `public/navdata/`.
- Добавлена строгая проверка дерева релиза `npm run check:tree`, чтобы старые файлы снова не попадали в проект.
- В публикационном GitHub Actions добавлен вывод версии для подтверждения того, что публикуется именно 1.2.0.
- Алгоритм создания URL, GPX, поля UTC, разбор маршрута и визуализация оставлены неизменными.

## Проверки

Локально успешно выполнены:

- `npm run check:tree` — полный комплект исходников и отсутствие старых модулей;
- `npm run check:build-config` — проверка конфигурации Rollup и последовательности публикации;
- `npm run check:imports` и `npm run check:exports` — разрешение зависимостей;
- `npm run typecheck:core` — строгая проверка TypeScript-модулей;
- `npm test` — разбор OFP, названия точек, GPX, SID/STAR, AIRAC, URL с UTC, имитация запуска и проверка сохранности данных при очистке.

Здесь не удалось установить `@windycom/plugin-devtools`: npm registry не разрешается (`EAI_AGAIN`). Поэтому полная сборка Rollup/Svelte и публикация в Windy **не подтверждены**.

Тесты Node.js / TypeScript и проверка целостности архива проводятся отдельно и не заменяют проверку `npm run build`.

## Оговорки

- Эффективное время URL округляется до трёхчасового слота; GPX сохраняет точные минуты.
- GPX содержит имена FIX, но Windy может отображать их собственными номерами.
- Данные маршрутов используются для визуализации и не заменяют официальные аэронавигационные источники.
