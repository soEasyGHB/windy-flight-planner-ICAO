# Аудит Windy Flight Route Analyzer v1.0.1

## Изменения относительно 1.0.0

1. В GPX стандартное `<time>` на первой подтверждённой точке вылета (`rtept` + именованном `wpt`), а также прежнее расширение `plannedDepartureUtc`; нет искусственных времён для остальных FIX.
2. При нажатии «Открыть штатный планировщик Windy» плагин устанавливает `@windy/store.timestamp` из ETD UTC **в рамках доступного прогноза**, после чего запускает штатный `rplanner`. Не передаёт маршрут, TAS, FL. Если Windy отказал — показано предупреждение в диагностике, открытие продолжится.
3. Формирование GPX-файла по двум подтверждённым ICAO аэропортам из исходного OFP с удалением суффиксов ВПП, включая маршрут с неизвестными участками (`-PARTIAL`). Ложное присвоение имени по случайному первому/последнему FIX блокируется.
4. Добавлен `<desc>` к каждому подписанному `rtept`/`wpt` в дополнение к `<name>` и `<cmt>`. Числовые маркеры в штатном Windy остаются возможны; после обновления Windy весной 2026 обнаружены жалобы на потерю подписей при импорте GPX.
5. Все предыдущие функции маршрута, GPS/GPX, iPad Share, диагностики и навигационных баз сохранены.

## Подтверждённые проверки

- TypeScript (модули), импорты/экспорты, структура файлов, Rollup-конфигурация.
- Локальные тесты: ICAO-парсер, AIRAC, CSV, GPX/XML, UTC, GPX-имена с ВПП, частичные маршруты, Share Sheet/скачивание, имитация `@windy/store`, отказ store, открытие планировщика без маршрута.
- GPX с подтверждённым аэропортом получает `time` **только** на его стартовой точке и не получает `metadata/time`.
- Все обязательные файлы присутствуют, устаревших модулей не осталось.

## Не подтверждено

- Установка npm-зависимостей в этой среде не удалась из-за DNS `EAI_AGAIN`, поэтому полноценный Rollup/Svelte build здесь отсутствует; требуется `npm run test:release` в Codespaces.
- Фактический приём времени старта и подписей штатным планировщиком Windy, iPad Share Sheet на устройстве — только после публикации. Задание `store.timestamp` синхронизирует общую метеошкалу, а не гарантированно внутреннее поле начала маршрута.
