# Проверка релиза Windy Flight Route Analyzer v0.9.2

Основа: полный исходный проект v0.9.1. Менялись только подписи составляющей ветра в `src/plugin.svelte`, версии проекта и проверочные файлы.

Визуальные изменения на графическом профиле:
- зелёная стрелка по маршруту + число, но без знака `+` и `kt` — попутная составляющая;
- красная стрелка навстречу + число без знака и `kt` — встречная;
- серая отметка `0` — чисто боковой ветер;
- в сводной строке выбранной точки и легенде удалены обозначения `kt` для продольной составляющей.

Полное направление и скорость исходного ветра с единицами оставлены в технических tooltip; вычисления и значения ветра не менялись. Сохранены графический профиль FL330–390, FL360, ISA deviation и тропопауза. Полная сборка Rollup требует `npm install && npm run build` в Codespaces.
