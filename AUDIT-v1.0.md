# Аудит Windy Flight Route Analyzer v1.0

## Изменения относительно v0.11.2

1. Строка `Частичный GPX готов…` и прочие уведомления экспорта удалены из основной карточки «Планировщик полёта» и перенесены под раскрываемый пункт «Настройки → Ошибки и предупреждения».
2. Неизвестные цифровые терминальные SID/STAR рядом с аэропортами вылета/прилёта пропускаются при построении схематичной линии. Известные точки с цифрами и координаты сохраняются. Неизвестные точки в середине маршрута по-прежнему формируют разрыв.
3. GPX 1.1 дополнен отдельными именованными `<wpt>`; имена подтверждённых FIX также остаются в `<rtept>`. Совместимость формата проверена, **но поведение меток в интерфейсе Windy не гарантируется**.
4. Обновлены version в `package.json` и `src/pluginConfig.ts` до `1.0.0`, документация релиза и скрипты удаления устаревших файлов. Прежний ID плагина сохранён.
5. Все пользовательские навигационные базы, функции GPX, Share Sheet на iPad и два главных блока сохранены. Удалённые погодные и офлайн-модули отсутствуют.

## Выполненные проверки

- `npm run check:tree` — наличие обязательных файлов и отсутствие устаревших модулей.
- `npm run check:build-config` — проверка сборочных настроек и проверки релиза перед публикацией.
- `npm run check:imports`, `npm run check:exports`, `npm run typecheck:core` — структура зависимостей и TypeScript.
- `npm test` — CSV, X-Plane, GitHub/AIRAC, маршруты, SID/STAR, GT/GPX, UTC, браузерное скачивание, системное «Поделиться», структура интерфейса и тест инициализации Svelte-кода.
- XML GPX проверяется через Python ElementTree, включая пространства имён, именованные `wpt` и `rtept`.

## Неподтверждённое

`npm install` в этой среде не может получить пакеты npm (`EAI_AGAIN`), поэтому **реальная компиляция Rollup/Svelte и генерация dist не подтверждены**. Фактическое отображение именованных GPX-точек в интерфейсе Windy и Share Sheet на реальном iPad также не проверено. Полная сборка и публикация обязаны проходить `npm run test:release` в GitHub Codespaces.
