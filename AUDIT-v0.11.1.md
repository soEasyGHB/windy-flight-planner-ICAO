# Аудит Windy Flight Route Analyzer v0.11.1

## Изменения относительно v0.11.0

- В разделе «Планировщик полёта» теперь **ровно две кнопки**: «Скачать GPX» и «Открыть штатный планировщик Windy».
- «Скачать GPX» вызывает на iPad системное «Поделиться» (`navigator.share` с GPX-файлом), позволяющее выбрать «Сохранить в Файлы». Для браузеров без файлового Share API — тот же обработчик запускает обычное скачивание по подготовленной Blob/data-ссылке.
- «Открыть штатный планировщик Windy» отправляет `bcast.emit('rqstOpen','rplanner')` **без третьего аргумента**: не отправляются координаты, GPX, TAS, FL, ETA, слои погоды и настройки. Если сам вызов падает, используется резервная ссылка `https://www.windy.com/distance` без параметров.
- Поля маршрута, GPX XML, предупреждения о неполном маршруте, настройки баз данных, диагностика и отрисовка маршрута оставлены без изменения.
- Обновлены версии package/pluginConfig, тест открытия в условной Windy-среде и установка через Codespaces.

## Выполненные проверки

- `npm run check:tree` — наличие всех обязательных файлов, отсутствие устаревших модулей, версия в файлах.
- `npm run check:build-config`, `npm run check:imports`, `npm run check:exports` — статические проверки Rollup, зависимостей и экспорта.
- `npm run typecheck:core` — строгая проверка TypeScript вспомогательных модулей.
- `npm test` — парсинг ICAO/AIRAC, GPX и его частичные сегменты, тест Web Share и fallback на браузерный download, имитация открытия штатного планировщика без параметров, проверка резервного перехода по URL, проверки навигационных файлов.
- ZIP — проверка CRC всех записей, повторная распаковка и повторные локальные тесты.

## Не проверено

- Rollup/Svelte в настоящем окружении Windy: зависит от установки npm-зависимостей, которая может быть недоступна в этой среде. Публиковать только после `npm run test:release` в GitHub Codespaces или после успешного build-job в GitHub Actions.
- Настоящий iPad Share Sheet и получение событием `rplanner` во всех версиях Windy не могут быть гарантированы без теста на устройстве. GPX предназначен для визуализации, не является одобренным навигационным документом.
