# Windy Flight Route Analyzer 1.1.2 — установка и тестирование

## Изменение передачи UTC

Ранее `href` штатного планировщика формировался автоматически и мог изменяться прямо в обработчике клика. Теперь кнопка **«1. Сформировать ссылку с UTC»** снимает значения полей, создаёт URL и показывает его в интерфейсе. Отдельная ссылка **«2. Открыть готовую ссылку в Windy»** открывает именно отображённый `href` (без мутации во время клика). После изменения даты, времени или маршрута ссылка скрывается до повторного формирования. Есть кнопка копирования URL для ручной проверки в Safari.

## Обновление GitHub Codespaces

Скачай и загрузи архив `Windy-Flight-Route-Analyzer-FULL-v1.1.2.zip` в корень репозитория, затем:

```bash
unzip -o Windy-Flight-Route-Analyzer-FULL-v1.1.2.zip
npm run cleanup:legacy
npm install --no-audit --no-fund
npm run test:release
```

`test:release` включает тесты маршрутов, GPX, URL и **полную сборку** Rollup/Svelte. Если она не проходит — не публикуй.

Если все команды успешны:

```bash
git add -A -- . ':(exclude)*.zip' ':(exclude)*.sha256'
git status --short
git commit -m "Add explicit Windy UTC URL preview v1.1.2"
git push origin main
```

Публикация: GitHub → Actions → `publish-plugin` → Run workflow → `main`. GitHub secret `WINDY_API_KEY` нужен только для публикации.

## Тест на iPad

1. На маршруте UUEE–UNNT выбери дату в пределах горизонта прогноза Windy и время **18:00 UTC**.
2. Нажми **«Сформировать ссылку с UTC»**. Убедись, что поле URL заканчивается на `?YYYY-MM-DD-18`.
3. Нажми **«Открыть готовую ссылку»**; проверь время в штатном планировщике.
4. Вернись в плагин, выбери **21:00 UTC**. Старая ссылка должна исчезнуть.
5. Снова сформируй ссылку — теперь она должна заканчиваться на `-21`.
6. Если Windy откроется не с тем временем, скопируй показанный URL и открой его в адресной строке Safari. Если вручную работает, а через кнопку нет, причина не в кодировании UTC, а в способе перехода или состоянии Windy.

**Ограничение:** URL, подтверждённый ручными тестами, использует трёхчасовые слоты, а не точные минуты. GPX сохраняет точное время. Любое применение к внутреннему ETD зависит от текущей версии Windy.
