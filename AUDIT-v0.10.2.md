# Аудит v0.10.2 — переход на Open-Meteo NOAA GFS

## Изменения в коде

- `src/plugin.svelte`: запрос прогноза перенаправлен на `loadWeather` без каких-либо настроек Vercel/Point Forecast; UI, ошибки и атрибуция обновлены.
- `src/weather.ts`: GFS `models=gfs_seamless`, `cell_selection=nearest`, батчи из трёх координат, UTC окна по ETA. Один ответ содержит температуру, RH, ветер, облачность и модельные геопотенциальные высоты для оценки тропопаузы. Ограничение 80 точек, HTTP ошибки и тайм-аут 30 секунд сохраняются.
- `src/tropopause.ts`: существующая аппроксимация температурной тропопаузы сохранена, используется из основного запроса GFS.
- `src/offlineReport.ts`: пояснение источника данных изменено на Open-Meteo GFS с атрибуцией.
- Удалены неиспользуемые `src/windyWeather.ts`, `api/windy-forecast.js`, `tests/test_windy_proxy_v010.mjs`; `vercel.json` остаётся как *необязательная* конфигурация статического сайта навигационных данных.
- `tests/test_open_meteo_v0102.mjs`: контроль URL, отсутствия ключа, совпадения GFS-источника для таблиц и тропопаузы, правильной обработки ошибок HTTP, отсутствующих уровней и лимита точек.
- `tests/test_new_v010.mjs`: прежние проверки графики (ISA, ветер, тропопауза, рекомендованные чётные/нечётные FL) адаптированы к прямому прогнозу.

## Проверки

Выполнить в корне:

```bash
npm run check:tree
npm run check:build-config
npm run check:imports
npm run check:exports
npm run typecheck:core
npm test
npm run build
npm run verify:release
```

Последние две команды требуют зависимостей Windy, Svelte и Rollup. Их результат необходимо зафиксировать отдельно — **исходный исходник, пройденный TypeScript и тесты не являются доказательством успешной компиляции UI-плагина**.

## Ограничения

- Модельные данные GFS могут быть интерполированы самим Open-Meteo по времени/высоте/пространству; прямое соответствие Windy на карте не гарантируется.
- GFS высотные параметры имеют более грубое пространственное разрешение, чем некоторые приземные модели.
- Тропопауза является модельной грубой оценкой, при недостатке данных отсутствует.
- Не является метеорологическим обеспечением рейса, не заменяет разрешённые высоты/ эшелоны, OFP, SIGWX, SIGMET или действия диспетчера.
