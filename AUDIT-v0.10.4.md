# AUDIT — Windy Flight Route Analyzer v0.10.4

## Обнаруженные дефекты v0.10.3

- `src/plugin.svelte`: кнопка GPX имела `disabled={busy}`, хотя `busy` использовался для фонового сетевого импорта навигационной базы и погодных запросов. Медленный/зависший запрос лишал пользователя экспорта локально сформированного GPX.
- Обработчик скачивания при доступной `navigator.share` сразу переключался на Web Share, не выполняя классическое скачивание; отказ Sharing не запускал альтернативу.
- Для неподдерживаемого `new File()` или других проблем экспорт прерывался, а ошибка выводилась в скрытых настройках.

## Исправления

- Основное скачивание сделано настоящей `<a download>` ссылкой с заранее подготовленным `blob:` URL; не зависит от `busy`, API-ключа или сети.
- `src/gpxDownload.ts` содержит генератор содержимого и имени файла, `Blob` ссылку и резервную `data:` ссылку; предоставляет `File` только для отдельной функции «Поделиться».
- Видимый рядом с кнопками `role="status"`; обновление и очистка URL при изменении маршрута/уничтожении компонента.
- Генерация GPX выполняется до построения геометрии на карте.
- Предусмотрены частичные GPX без вымышленных связей между неизвестными точками.
- Версия обновлена в `package.json` и `src/pluginConfig.ts` до `0.10.4`. Выполнена проверка наличия новых исходных файлов и тестов.

## Не проверено / ограничения

- Компиляция Rollup/Svelte и запуск опубликованного плагина — **не подтверждены**, потому что `npm install` в этой среде завершился DNS `EAI_AGAIN` для registry.npmjs.org, а пакета `rollup` здесь нет. Публикацию разрешать только после `npm run test:release` в GitHub Codespaces.
- iPad Safari/WebKit — не проверено физическим устройством. Есть явный альтернативный путь через системное меню «Поделиться».
- GPX предназначен для визуализации, не для навигации.
