# Обновление AIRAC для Windy Flight Route Analyzer 2.0.1

1. Откройте папку Google Drive [Windy-NAVDATA](https://drive.google.com/drive/folders/14eS_Ir19Uv7FPc2cVZWBR6_yKBvGTu5C).
2. В файле **`navdata.zip`** замените три файла **одного цикла AIRAC**: `earth_fix.dat`, `earth_nav.dat` и `earth_awy.dat`.
3. Загрузите обновлённый `navdata.zip` в ту же папку вместо предыдущего архива.
4. После автоматической синхронизации в Windy откройте **Настройки → Навигационные базы данных → Проверить базу данных**.

Обновление данных через Google Drive зависит от настроенной синхронизации и может выполняться не сразу. Права на использование и распространение навигационных файлов должны быть соблюдены. Эти данные служат для справочной визуализации, а не для эксплуатационной IFR-навигации.
