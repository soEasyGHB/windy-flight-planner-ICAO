# X-Plane navdata на iPad — v0.5.1

## Вариант 1. Импорт прямо в Windy (рекомендуется)

1. В iPad «Файлы» выберите каталог с `earth_fix.dat`, `earth_nav.dat`, `earth_awy.dat` одного AIRAC.
2. Выделите эти три файла и нажмите «Сжать», чтобы получить **один ZIP**. Или используйте уже существующий ZIP, если в нём есть эти три файла.
3. В Windy откройте наш плагин → «Навигационная база X-Plane» → «Выбрать один ZIP или три файла X-Plane».
4. Выберите ZIP (его iPad обычно разрешает выбрать), затем «Импортировать X-Plane в Windy».
5. Дождитесь вывода количества точек и сегментов. Постройте маршрут и выбирайте погодные слои.

**Почему ZIP:** iPad Safari иногда не позволяет выбрать неизвестное расширение `.dat`, особенно когда HTML-поле выбора установило фильтр `.dat`. В v0.5.1 фильтр снят, ZIP дополнительно распаковывается внутри плагина. Данные не уходят на сервер, но локальная база не сохраняется между перезагрузками вкладки.

Если ZIP не удаётся создать, можно в «Файлах» переименовать три `.dat` в `earth_fix.txt`, `earth_nav.txt`, `earth_awy.txt` и выбрать их по отдельности.

## Вариант 2. Постоянная база в GitHub (только для баз с разрешённой лицензией)

1. Создайте ZIP с `earth_fix.dat`, `earth_nav.dat`, `earth_awy.dat` одного цикла.
2. В GitHub откройте публичный репозиторий → `navdata-input/` → Add file → Upload files → выберите ZIP → Commit changes.
3. GitHub Actions запустит `build-navdata`; после успешного выполнения появятся файлы `public/navdata/{points.csv,airways.csv,manifest.json}`.
4. В плагине Windy укажите URL публичного репозитория и нажмите «Обновить базу из GitHub».
5. В следующий AIRAC замените старый ZIP на новый. Не оставляйте несколько архивов одновременно.

В GitHub не нужно открывать каждый `.dat` отдельно. Без авторизации из плагина нельзя добавлять файлы в репозиторий напрямую.

**Внимание:** персонально лицензированные Navigraph/Jeppesen/X-Plane базы нельзя публиковать на GitHub без разрешения лицензии; для них используйте вариант 1.

## Развёртывание исправления в старый проект из Codespaces

Загрузите архив `Windy-Flight-Route-Analyzer-UPDATE-v0.5.1.zip` в корень Codespaces. В Terminal выполните:

```bash
unzip -o Windy-Flight-Route-Analyzer-UPDATE-v0.5.1.zip
npm install
npm test
npm run build
git add -A
git commit -m "Fix X-Plane import on iPad"
git pull --rebase origin main
git push origin main
```

Если `git pull --rebase` показывает CONFLICT, остановитесь и устраните конфликт прежде чем продолжать. После push выполните GitHub → Actions → `publish-plugin` → Run workflow.

Геометрия трасс не проверяет применимость высот/направлений, NOTAM и действительность цикла. Не используйте как утверждённую навигационную базу.
