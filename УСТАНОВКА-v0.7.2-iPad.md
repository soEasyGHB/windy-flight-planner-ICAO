# Установка исправления v0.7.2 (iPad)

Не заменяй рабочую Google Drive-навигационную базу. Понадобится только архив обновления кода.

1. Скачай `Windy-Flight-Route-Analyzer-UPDATE-v0.7.2.zip`.
2. Загрузи ZIP через Safari → GitHub Codespaces → Explorer → Upload в корень репозитория (рядом с `package.json`).
3. Убедись, что `git status` не показывает конфликта/rebase. Выполни:

```bash
git pull --ff-only origin main
unzip -o Windy-Flight-Route-Analyzer-UPDATE-v0.7.2.zip
npm install
npm run typecheck:core
npm test
npm run build
```

4. Если **все** проверки зелёные, выполни:

```bash
git add src/plugin.svelte src/weather.ts src/pluginConfig.ts package.json tests/test_weather.mjs README.md УСТАНОВКА-v0.7.2-iPad.md
git commit -m "Fix planner buttons and named FL300-400 weather v0.7.2"
git push origin main
```

5. GitHub → Actions → publish-plugin → Run workflow. После успешной публикации открой Windy повторно.

В интерфейсе: построй маршрут, задай ETD UTC и TAS (450 kt по умолчанию). Нажми Route Planner, GPX или «Получить профиль и открыть». В таблице прогноза и нижнем профиле будут указаны **настоящие имена точек из плана**, а высоты FL300–400 с шагом 10. Кнопки Route Planner и GPX показывают причины невозможности экспорта — например, нераспознанную ATS-трассу — вместо молчаливого блокирования.

Если Windy запущен как iPad-приложение, внешняя ссылка может требовать ручного открытия в Safari; для GPX используй Share → Save to Files, затем импорт в Route Planner на windy.com. Достоверность текущего AIRAC и доступность прогноза проверяй отдельно. Не используй инструмент для эксплуатационной IFR-навигации.
