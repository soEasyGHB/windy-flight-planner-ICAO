# Аудит релиза v0.10.0 (Windy GFS + расчёт FL)

**Основа:** полный архив v0.9.5; сохранены основные файлы плагина, навигационная обработка GitHub/Drive, GPX/Route Planner, отображение маршрута и offline-report.

## Реализация по пунктам

| № | Требование | Реализация |
|---|---|---|
| 1 | Поднять новый планировщик над штатным | Пятая карточка `fr-section-our-planner` перед `fr-section-export`, `openWeatherProfile()` непосредственно на главной странице |
| 2 | Тропопауза на всём маршруте, источник высоты | Новый `src/tropopause.ts`: модельная температура + **геопотенциальная высота** на 700–50 hPa; не используется прежний `standardAltitudeM()` для высоты тропопаузы. Отдельная шкала в `src/profileChart.ts`, сегменты соседних доступных точек не обрезаются FL330–390 |
| 3 | Границы ISA пунктиром с подписью | Marching squares по сетке «точки × FL», контуры ±5, ±10, ±15, ±20, ±25 и 0 с подписями, приглушённый фон |
| 4 | Смягчить цвета стрелок | Мягкий зелёно-серый для tailwind и пыльно-розовый для headwind, ниже насыщенность и непрозрачность |
| 5 | Рекомендованный FL для двух паритетов | `recommendFlightLevels()`: средняя продольная составляющая по дистанциям от маршрута; отрицательный результат означает наименьший встречный среди кандидатов. Убраны поле FL и линия выбранного FL; показаны две голубые линии и два значения FL в footer |
| 6 | Таблица из Windy | `src/windyWeather.ts` + серверная функция `api/windy-forecast.js`, источник `Windy Point Forecast GFS`, конверсия `K → °C`, `m/s → kt`, `u/v → FROM °`; отсутствуют фальшивые fallback-данные |

## Обнаруженные внешние ограничения

Windy Point Forecast v2 имеет лицензируемую модель GFS (ECMWF отсутствует), поддерживает только определённые уровни `[850, 800, 700, 600, 500, 400, 300, 200, 150] hPa` в данной реализации; промежуточный FL — интерполяция. В тестовом тарифе Windy возвращает изменённые данные; использовать его как точный прогноз нельзя. Windy API не имеет параметра тропопаузы, поэтому эта величина остаётся **отдельной модельной оценкой**. Источники и тарифы: https://api.windy.com/point-forecast/docs , https://api.windy.com/point-forecast/pricing .

**Не сертифицировано для воздушной навигации или выбора рабочего эшелона.**
