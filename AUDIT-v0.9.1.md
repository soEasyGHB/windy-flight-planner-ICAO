## Тестовые инварианты

1. Путевой угол EAST — 090°, WEST — 270° (при экваториальных точках).
2. Ветер FROM 270° / 50 kt на курсе 090°: +50 kt попутного.
3. Ветер FROM 090° / 50 kt: −50 kt встречного.
4. Ветер FROM 000° / 50 kt: 0 kt продольного, 50 kt бокового.
5. Ветер FROM 354° / 50 kt: примерно +5 kt попутного, а не +50.
6. Направления 359°/000° и точки с одинаковыми координатами обрабатываются.
7. Вся диаграмма работает по FL330–FL390 с выделенным FL360;
   ISA, температура, линия тропопаузы, нажатие на точку сохранены.

## Ограничения

- Курс вычисляется по прямым между именованными FIX, а не фактической трассе ATS.
- Расчётные ETA не учитывают ветер и не являются расчётами путевой скорости GS.
- Windy weather layer и Open-Meteo профиль — независимые источники.
- Нужна финальная `npm run build` + `npm run verify:release` в Codespaces,
  если в локальной среде нет Rollup/Windy SDK.
