# Установка Windy Flight Route Analyzer v1.0.2

## Кнопки «Планировщик полёта»

1. **Скачать GPX**: системное «Поделиться» на iPad; скачивание файла в прочих браузерах. GPX содержит точный ETD UTC на точке вылета.
2. **Открыть штатный планировщик Windy**: просто открывает пустой встроенный планировщик и синхронизирует время карты, насколько это допускает Windy.
3. **Передать маршрут и UTC в Windy**: восстанавливает команду, существовавшую в версиях до v1.0, `rqstOpen('rplanner', {coords, view:'ifr'})` и предварительно задаёт `store.timestamp` по выбранным полям UTC.

### Ограничения, которые нельзя обойти кнопкой

- Внутренний вызов Windy **не является публичным API импорта GPX**. Сам GPX XML не загружается непосредственно в штатный планировщик по API. Названия FIX и точное ETD могут остаться нераспознанными в штатном планировщике.
- Если Windy не принял координаты, в «Настройки → Ошибки и предупреждения» появится резервная ссылка `/distance/...` с маршрутом. Время прогноза в этой ссылке округляется до 3 часов, поэтому оно **не эквивалентно точному времени вылета**. Точное ETD хранится в GPX.
- Если исходный маршрут частичный, передаётся только самый длинный непрерывный подтверждённый участок, разрывы не соединяются. Пользователь получает предупреждение.
- Прогноз Windy не имеет бесконечного горизонта, а дата вне горизонта не может быть установлена.
- Указанное поведение нельзя гарантировать без проверки непосредственно в установленном Windy.

## Установка из архива в GitHub Codespaces

Загрузить `Windy-Flight-Route-Analyzer-FULL-v1.0.2.zip` в корень репозитория и запустить:

```bash
unzip -o Windy-Flight-Route-Analyzer-FULL-v1.0.2.zip
npm run cleanup:legacy
npm install --no-audit --no-fund
npm run test:release
```

Только после успешной сборки и тестов:

```bash
git add -A -- . ':(exclude)*.zip' ':(exclude)*.sha256'
git status --short
git commit -m "Restore route and UTC handoff v1.0.2"
git push origin main
```

Затем GitHub → Actions → `publish-plugin` → Run workflow. Секрет `WINDY_API_KEY` требуется только для публикации. GPX/API прогнозов никаких ключей не требуют.

**Безопасность:** это вспомогательный визуализатор, не источник данных для оперативной аэронавигации, расчётов экипажа или выполнения полёта.
